# Politicas de RabbitMQ

Durante la validacion final no se desplegaron politicas avanzadas de DLQ,
reintentos o TTL especificas. La entrega se basa en una configuracion sencilla
centrada en correctness e idempotencia a nivel de aplicacion.

Si mas adelante se extiende la practica, este es el lugar natural para
documentar politicas operativas adicionales.
