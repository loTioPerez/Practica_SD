# Desarrollo Local

Utilidades minimas para levantar la infraestructura base de desarrollo.

## Ficheros

- `docker-compose.yml`: Redis y RabbitMQ para ejecucion local
- `seed_state.py`: carga el estado inicial de entradas en Redis

Estos artefactos se usan tanto en validacion local como en ensayos previos a un
despliegue distribuido en LAN o AWS.
